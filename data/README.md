\# Data sources



Raw data files are not redistributed in this repository.



This analysis uses publicly available data from the International Renewable Energy Agency (IRENA) and Our World in Data.



\## Installed renewable energy capacity



\*\*Our World in Data — Installed capacity for different renewable technologies\*\*



https://ourworldindata.org/grapher/installed-global-renewable-energy-capacity-by-technology



The series is based on IRENA's Renewable Energy Statistics and is used in this project as the global installed capacity stock by technology.



\## Renewable power generation costs



\*\*IRENA — Renewable Power Generation Costs in 2025\*\*



https://www.irena.org/Publications/2026/Jul/Renewable-Power-Generation-Costs-in-2025



This report and its accompanying data file provide the total installed cost data used for:



\- Onshore wind

\- Offshore wind

\- Solar PV

\- Hydropower

\- Bioenergy

\- Battery storage

\- Battery deployment volumes

\- IRENA forward cost projections used for comparison



\## Reproducing the analysis



To reproduce the project:



1\. Download the original source files from the links above.

2\. Place the required files inside the local `data/` directory.

3\. Run `analysis.R` from the project root.



The raw source files are intentionally not included in this repository.
